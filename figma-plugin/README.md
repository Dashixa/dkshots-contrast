# DkShots для Figma

Плагин проверяет любой выбранный интерфейс на шести фонах DkShots. Для каждого фона отдельно вычисляется средний визуальный процент по всем видимым пикселям, включая градиенты и полупрозрачные области.

## Установка для разработки

1. В корне проекта выполните `pnpm install` и `pnpm build:figma`.
2. Откройте настольную Figma и файл дизайна.
3. Выберите **Plugins → Development → Import plugin from manifest…** и укажите [`manifest.json`](./manifest.json).
4. Запустите **DkShots — Проверка контрастности иллюстраций** из раздела Development.

Скомпилированные `build/code.js` и `build/ui.html` уже входят в репозиторий и архив плагина. После изменения исходников повторите `pnpm build:figma` и перезапустите плагин в Figma.

При публикации в Figma Community замените локальный `id` в `manifest.json` на ID, который выдаст Figma для зарегистрированного плагина.

## Как пользоваться

- Кликните по слою, группе, компоненту, инстансу или фрейму в рабочей области Figma. Плагин автоматически экспортирует выбранный объект в PNG шириной или высотой 500 px и проверит его на каждом фоне.
- Нажмите на карточку фона, чтобы увидеть результат и превью.
- Если у фрейма есть собственная заливка, она попадёт в экспорт. Для анализа прозрачной иллюстрации выберите слой или группу без фоновой заливки.

Процент — сравнительный визуальный индекс DkShots, а не сертификат соответствия WCAG. Подсчёт использует яркость и коэффициент контраста WCAG для каждого пикселя после композитинга с фоном. Полностью прозрачные пиксели исключаются. Исходный документ Figma плагин не изменяет; сеть ему не нужна.

Официальная [инструкция Figma по импорту плагина](https://help.figma.com/hc/en-us/articles/360042786733-Create-a-classic-plugin-for-development).
