# DkShots — Проверка контрастности

**Tagline:** Проверяйте контрастность любого элемента на фоновых токенах.

**Category:** Design tools

**Description:**

DkShots помогает проверить, насколько выбранный слой, группа, компонент, инстанс или фрейм заметен на фоновых цветах интерфейса.

Выберите элемент в рабочей области Figma — плагин экспортирует его в разрешении до 500 px и автоматически рассчитает результат для шести фоновых токенов. При анализе учитываются прозрачность, градиенты и все видимые пиксели элемента. Результат для каждого фона показывается в процентах.

Возможности:

- автоматический анализ текущего выделения;
- отдельный результат для каждого фонового цвета;
- корректный alpha compositing прозрачных изображений;
- анализ градиентов по всей площади элемента;
- отсутствие сетевых запросов и передачи данных.
