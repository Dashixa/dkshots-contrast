# DkShots — Проверка контрастности иллюстраций

SPA на React, TypeScript и Tailwind CSS. Загружает PNG и SVG, оценивает изображение отдельно на шести фонах и показывает средний процент контраста.

## Запуск

```bash
pnpm install
pnpm dev
```

Локальный адрес после запуска: [http://localhost:5173/](http://localhost:5173/).

Проверка production-сборки: `pnpm build`.

## Плагин Figma

В каталоге [`figma-plugin`](./figma-plugin) находится версия для Figma. Она автоматически анализирует любой выбранный на холсте слой, группу, компонент, инстанс или фрейм. Готовый плагин собирается командой `pnpm build:figma`; инструкции по импорту — в [README плагина](./figma-plugin/README.md).

## Как считается результат

- Изображение масштабируется до 500 пикселей по большей стороне, сохраняя пропорции. Исходный alpha-канал сохраняется как маска; пиксели с alpha меньше половины максимальной alpha изображения исключаются, чтобы почти невидимое сглаживание краёв не искажало оценку.
- Для каждого фона canvas сначала заливается цветом фона, затем поверх рисуется изображение. Пиксели берутся только через `getImageData()` после смешивания цветов.
- Для каждого учитываемого пикселя коэффициент 1:1 преобразуется в 0%, а 2:1 или выше — в 100% по логарифмической шкале. Показанный процент — среднее этих оценок по всей иллюстрации. Так светлые иллюстрации на белом фоне не получают искусственно низкую визуальную оценку из-за порога 3:1. Этот процент — сравнительный индекс приложения, а не официальная отметка соответствия WCAG.
- Полностью прозрачное изображение отображается как отдельное состояние без оценки.
- Анализ назначается через `requestAnimationFrame`; отменённые выборы не сканируются. При смене фона готовые результаты выбираются из памяти, а обновление отображения также объединяется в один кадр.
